How to use examples and docstrings

1. To inspect a function's docstring in the REPL or script:

   - Start Python and `import` the module, then use `help()` or `.__doc__`.

2. Run the reversal demo:

```bash
python .\basics\Daily-practice\day01\reverse_demo.py
```

Notes for migrating concepts to Go

- Python string immutability ~ Go string immutability
- Use `strings.Builder` in Go for efficient string concatenation
