Interview Answer

Reverse Integer means reversing digits
without converting the integer to a string.

We repeatedly extract the last digit
using modulus operator and build the
reversed number.

Algorithm

1. Initialize result = 0

2. While n > 0

    Extract last digit

    digit = n % 10

    Append digit

    result = result*10 + digit

    Remove last digit

    n = n // 10

3. Return result


Complexity

Time Complexity

O(d)

d = number of digits

Time = O(d)
